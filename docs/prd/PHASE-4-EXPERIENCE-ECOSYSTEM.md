# PRD — Phase 4: Experience & Ecosystem

**Product:** QuorentX IQ  
**Phase:** 4 — Experience & ecosystem  
**Depends on:** Phases 1–2 (Phase 3 modules optional)  
**Status:** Spec

---

## 1. Goal

Extend beyond recruiter tooling: branded candidate experience, async one-way video, personalized communications, mock/practice mode, workplace chat + HRIS connectors, and live coding assessment integration — cementing full-stack differentiation.

---

## 2. In scope

| Capability | Description | Priority |
|------------|-------------|----------|
| Candidate portal | Branded status, prep materials, schedule self-serve where allowed | P0 |
| Async one-way video | Timed prompts; structured review by panel | P0 |
| Personalized candidate comms | Templates + triggers (invite, reminder, decision) | P1 |
| Mock interview / practice mode | Candidate-side rehearsal with feedback | P0 |
| Slack / Teams integrations | Interview reminders, score nudges | P1 |
| HRIS integrations | Workday/BambooHR-class sync (phased providers) | P2 |
| Live coding assessment integration | Embed or deep-link coding rounds (extend current IQ runner) | P0 |

---

## 3. Out of scope

Building a full ATS replacement; consumer social networking; unpaid job board marketplace.

---

## 4. User stories

1. As a candidate, I practice a mock round and feel prepared — not ghosted.  
2. As a recruiter, I send branded updates without leaving IQ.  
3. As an engineer interviewer, I launch a coding assessment from the same kit.  
4. As TA ops, interview events appear in Slack/Teams with deep links.

---

## 5. Success metrics

- Candidate NPS / CSAT on portal experience  
- Show-up rate ↑ with reminders + practice mode  
- % of technical loops using coding integration  
- Reduction in “tool sprawl” seats per customer (sales metric)

---

## 6. Exit criteria

Reference customer runs async + live + coding + practice mode in one branded portal, with at least one chat and one HRIS/ATS connector live.
